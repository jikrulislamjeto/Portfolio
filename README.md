## 📌 About the Project

This is my personal portfolio website, built to showcase my development journey, technical expertise, and projects in one place.

The website features a modern interface, responsive layouts, interactive components, and dedicated pages for my background, projects, and problem-solving activities. It also provides easy access to my professional information and online presence.

The project is designed with reusable components and a structured codebase to make future improvements and maintenance easier.

## ✨ Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Modern User Interface:** Clean layouts with interactive elements and smooth visual transitions.
- **Dark and Light Theme:** Switch between themes for a comfortable browsing experience.
- **Dynamic Navigation:** Active route highlighting and a mobile-friendly navigation menu.
- **Hero Section:** Introduction and quick access to important portfolio sections.
- **About Me:** Personal introduction, interests, and development journey.
- **Technical Skills:** Organized presentation of programming languages, frameworks, libraries, and tools.
- **Education Section:** Academic background and relevant learning experiences.
- **Projects Showcase:** Dedicated section for exploring selected projects.
- **Project Details Pages:** Individual pages with additional project information.
- **Problem-Solving Section:** Coding practice profiles and competitive programming information.
- **Contact Section:** Easy navigation to contact information and professional links.
- **SEO Support:** Page metadata and search-engine-friendly information.
- **Scroll Reveal Animations:** Subtle animations as content enters the viewport.
- **Toast Notifications:** User-friendly notifications using Sonner.
- **Reusable Components:** Modular components for easier maintenance and scalability.

## 📋 Prerequisites

Before running this project locally, make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm, which comes with Node.js
- [Git](https://git-scm.com/)
- A code editor such as [Visual Studio Code](https://code.visualstudio.com/)

## ⚙️ Installation and Setup

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/jikrulislamjeto/Portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open the Website

Visit the following URL in your browser:

[http://localhost:3000](http://localhost:3000)

The development server will display the portfolio locally.

## 🌍 Deployment

The portfolio is deployed using [Vercel](https://vercel.com/).

To deploy your own version:

1. Push the project to a GitHub repository.
2. Import the repository into Vercel.
3. Configure any required environment variables.
4. Deploy the application.
5. Test the deployed pages, navigation, and responsive layouts.
